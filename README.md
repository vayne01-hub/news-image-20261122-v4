# One Day, Thirty Stories — News Image 20261122

A deterministic Node 22 program (standard library only) that draws a 1024×1024 poster of thirty verified news stories from Sunday 22 November 2026, grouped into seven region cards. Every story was reported by at least two independent sources on the day.

## Run
